# CleanPic Metadata Stripper (Batch Mode)

A lightning-fast, local web tool to strip EXIF, XMP, IPTC, and AI generation metadata from **multiple images at once**.

### How to use:
1. Double-click `index.html` to open it in your web browser (Chrome, Edge, Firefox, Brave).
2. Drag and drop multiple images (PNG, JPEG, WebP) into the upload box (or click to browse).
3. The tool automatically processes all images in parallel, rendering them onto an HTML5 canvas and stripping all metadata.
4. Click **Download All** to save every ready, cleaned image as a separate file — no ZIP archive. You can still use each image’s **Download Clean** button.
5. If your browser asks, allow multiple/automatic downloads. If it blocks the batch, allow downloads for this page and retry, or use the individual buttons.

*100% Client-side processing — your photos never leave your computer, and zero server uploads are made.*
